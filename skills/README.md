# 스킬

스킬 두 개의 초안입니다. 회사에서 쓰는 AI 코딩 앱에 배포해서 씁니다.

| 스킬 | 언제 쓰는가 | 파일 |
| --- | --- | --- |
| 온보딩 진행 스킬 | 디자이너가 온보딩 과정을 진행할 때. 단위 글을 설명하고 실습을 진행시킵니다 | `onboarding-guide/SKILL.md` |
| 디자이너용 작업 규칙 스킬 | 온보딩이 끝난 뒤에도, 디자이너가 제품 코드의 수정을 요청할 때마다 | `designer-work-rules/SKILL.md` |

## 배포할 때 회사에서 정할 것

- 온보딩 진행 스킬은 이 레포의 `units/`, `exercises/`, `paths/`와 회사 사본의 `company/`를 읽습니다. 스킬과 함께 이 폴더들을 묶어서 배포할지, 디자이너가 레포를 받아 두게 할지 정합니다.
- 디자이너용 작업 규칙 스킬의 "회사 설정" 항목을 채웁니다. 디자이너가 수정하는 폴더의 목록, 디자인 시스템 패키지의 이름, PR 설명 형식입니다.
- 스킬 파일의 형식은 `SKILL.md` 하나에 이름과 설명을 맨 위에 적는 방식으로 썼습니다. 쓰는 앱이 다른 형식을 요구하면 본문은 그대로 두고 맨 위의 속성만 맞춥니다.
