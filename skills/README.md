# 스킬

AI에게 주는 지침 두 개입니다.

| 지침 | 언제 쓰는가 | 파일 | 쓰는 방법 |
| --- | --- | --- | --- |
| 온보딩 진행 | 디자이너가 온보딩 과정을 진행할 때. 단위 글을 설명하고 실습을 진행시킵니다 | `onboarding-guide/SKILL.md` | 설치할 필요가 없습니다. 이 레포 폴더를 AI 코딩 앱에서 열면 `AGENTS.md`가 이 파일을 읽게 합니다 |
| 디자이너용 작업 규칙 | 온보딩이 끝난 뒤에도, 디자이너가 제품 코드의 수정을 요청할 때마다 | `designer-work-rules/SKILL.md` | 제품 레포에서 작업할 때 적용되어야 하므로 따로 배포해야 합니다 |

## 디자이너용 작업 규칙을 배포할 때

- 스킬 파일에는 회사나 레포에 따라 달라지는 값이 없습니다. 파일을 그대로 복사해서 배포하면 됩니다. 회사에서 쓰는 AI 코딩 앱의 스킬 배포 방식에 맞춰 묶습니다.
- 레포마다 다른 값(디자이너가 수정해도 되는 폴더 등)은 각 제품 레포의 지침 파일에 "디자이너 작업 범위" 항목으로 적습니다. 양식은 `requests/designer-scope-section.md`입니다. 이 항목이 없는 레포에서는 스킬이 파일을 수정하지 않습니다.
- 스킬 파일의 형식은 `SKILL.md` 하나에 이름과 설명을 맨 위에 적는 방식으로 썼습니다. 쓰는 앱이 다른 형식을 요구하면 본문은 그대로 두고 맨 위의 속성만 맞춥니다.
