# 연습 레포 경로

연습 레포에서 화면을 띄우고, 고치고, 충돌을 복구해 보는 경로입니다. 제품 레포 경로보다 먼저 따라갑니다. 연습 레포는 디자인 시스템이 설치되어 있고 실제 서비스와 연결되지 않은 작은 레포입니다. 이 파일은 견본이고, 회사에서는 `company/paths/`에 실제 레포 이름으로 경로를 둡니다. 단위를 아래 순서대로 읽습니다.

## 읽기

1. A0 이 과정이 다루는 것과 다루지 않는 것
2. A1 개발 프로젝트는 폴더이고 코드는 텍스트 파일이다
3. A2 확장자로 파일의 역할 구분하기
4. A3 AI 코딩 앱에서 프로젝트 폴더를 열고 작업을 지시하기
5. A4 node와 package.json
6. A5 디자인 시스템은 패키지로 설치되어 있다
7. A9 사내 스킬 목록
8. A6 개발 환경 셋업과 점검 (연습 레포)
9. A7 로컬에서 화면 띄우기와 스토리북 열기 (연습 레포)
10. A8 AI에게 코드에 대해 질문하기 (연습 레포)

## 뷰 수정

11. B1 git의 구조
12. B2 복구 가능한 범위와 실제로 조심할 행동
13. B3 변경 내역(diff) 읽기
14. B6 화면은 부모와 자식의 트리로 기술된다
15. B8 Figma 컴포넌트와 코드 컴포넌트의 대응
16. B7 디자인 토큰이 코드에 정의된 방식
17. B9 디자인 시스템 사용법 스킬과 스토리북으로 컴포넌트를 찾고 쓰기
18. B4 작업 한 번의 전체 절차 (연습 레포)
19. B5 충돌과 "내 변경이 보이지 않는 상황"을 복구하기 (연습 레포)
