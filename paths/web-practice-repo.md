# 연습 레포 경로

연습 레포에서 화면을 띄우고 고쳐 보는 경로입니다. 제품 레포 경로보다 먼저 따라갑니다. 연습 레포는 디자인 시스템이 설치되어 있고 실제 서비스와 연결되지 않은 작은 레포입니다. 이 파일은 견본이고, 회사에서는 `company/paths/`에 실제 레포 이름으로 경로를 둡니다.

단위를 아래 순서대로 읽습니다. "실습"이라고 적힌 줄은 `exercises/`의 실습입니다.

## 1부: 셋업 없이 할 수 있는 것

프로젝트 셋업이 끝나지 않았어도 여기까지는 진행할 수 있습니다.

1. A0 이 과정이 다루는 것과 다루지 않는 것
2. A1 개발 프로젝트는 폴더이고 코드는 텍스트 파일이다
3. A2 확장자로 파일의 역할 구분하기
4. A3 AI 코딩 앱에서 프로젝트 폴더를 열고 작업을 지시하기
5. A10 작업에 맞는 모델과 추론 강도 고르기
6. B1 git의 구조
7. 실습 E-git-01 커밋하고 브랜치를 만들어 보기
8. B2 복구 가능한 범위와 실제로 조심할 행동
9. B3 변경 내역(diff) 읽기
10. 실습 E-git-02 변경 내역에서 요청하지 않은 변경 찾기
11. B5 충돌과 "내 변경이 보이지 않는 상황"을 복구하기
12. 실습 E-git-03 충돌을 내고 해결하기
13. 실습 E-git-04 사라진 것처럼 보이는 변경을 되찾기
