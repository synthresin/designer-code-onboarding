# 제품 레포 경로(웹)

제품 웹 레포에서 PR을 올려 머지하는 경로입니다. 연습 레포 경로를 마친 사람이 따라갑니다. 이 파일은 견본이고, 회사에서는 `company/paths/`에 실제 레포 이름으로 경로를 둡니다.

연습 레포 경로에서 읽은 일반 단위와 플랫폼(웹) 단위, 이미 한 git 실습은 다시 하지 않습니다.

## 읽기

1. A6 개발 환경 셋업과 점검 (제품 레포)
2. A7 로컬에서 화면 띄우기와 스토리북 열기 (제품 레포)
3. A8 AI에게 코드에 대해 질문하기 (제품 레포)
4. 마무리 과제: 자신이 디자인한 화면 하나를 로컬에서 띄우고, 그 화면의 코드 파일과 사용된 디자인 시스템 컴포넌트를 다른 사람에게 설명합니다.
