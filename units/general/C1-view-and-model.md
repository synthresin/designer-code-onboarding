# 뷰와 모델의 분리

화면을 만드는 코드는 하는 일에 따라 나뉩니다. 무엇을 어떻게 보여 줄지를 정하는 코드가 뷰이고, 데이터와 그 데이터에 대한 규칙을 다루는 코드가 모델 또는 로직입니다. 디자이너가 고치는 것은 뷰입니다. 로직을 바꿔야 하는 시점을 알아차리고 멈추는 것이 화면 구성 작업 범위에서 가장 중요한 능력입니다.

## 코드가 하는 세 가지 일

| 일 | 내용 | 예 |
| --- | --- | --- |
| 뷰 | 받은 데이터를 화면에 어떻게 보여 줄지 정합니다 | 남은 휴가 일수를 카드의 오른쪽 위에 굵게 표시합니다 |
| 데이터 요청 | 서버에서 데이터를 가져오고 서버로 보냅니다 | 이 구성원의 남은 휴가 일수를 서버에 요청합니다 |
| 로직 | 데이터에 대한 규칙과 계산입니다 | 남은 휴가 일수를 어떻게 계산하는지, 누가 신청할 수 있는지 정합니다 |

개발자들은 이 구분을 MVC 같은 이름으로 부르기도 합니다. 이름은 프로젝트마다 다르지만, 보여 주는 코드와 규칙을 다루는 코드를 나눈다는 생각은 같습니다.

## 왜 나누나요

뷰는 자주 바뀌고, 틀려도 눈에 보입니다. 로직은 틀리면 데이터가 잘못 계산되거나 잘못 저장되는데, 화면만 봐서는 알기 어렵습니다. 둘이 나뉘어 있으면 뷰를 고칠 때 로직이 깨질 위험이 줄어들고, 개발자가 나중에 로직을 교체해도 뷰는 그대로 둘 수 있습니다.

둘 사이의 경계는 뷰가 받는 데이터의 형태입니다. 뷰는 "이름, 남은 일수, 상태를 받아서 이렇게 보여 준다"까지만 알고, 그 값이 어디서 어떻게 만들어졌는지는 모릅니다. 이 경계를 지키면서 뷰 안쪽만 고치는 것이 디자이너의 작업입니다.

## 뷰의 변경인지 로직의 변경인지 구분하기

"보여 주는 방식이 바뀌는가, 아니면 무엇이 사실인지 또는 무엇이 저장되는지가 바뀌는가"를 묻습니다.

| 요청 | 구분 |
| --- | --- |
| 남은 일수를 더 크게 보여 준다 | 뷰 |
| 카드의 정보 순서를 바꾼다 | 뷰 |
| 이미 받고 있는 날짜를 "3일 전" 형식으로 보여 준다 | 뷰 |
| 남은 일수에서 예정된 휴가를 빼고 보여 준다 | 로직. 계산이 바뀝니다 |
| 화면에 없던 정보인 입사일을 추가한다 | 받고 있는 데이터에 입사일이 있으면 뷰, 없으면 데이터 요청의 변경 |
| 버튼을 관리자에게만 보여 준다 | 로직. 권한의 규칙입니다 |
| 저장 버튼을 누르면 확인 없이 바로 저장한다 | 로직. 저장되는 시점이 바뀝니다 |

경계에 있는 경우가 있습니다. 목록의 정렬 순서는 화면에서만 바꾸는 것이면 뷰에 가깝지만, 서버가 정렬해서 보내 주고 있다면 데이터 요청의 변경입니다. 판단이 서지 않으면 AI에게 어느 쪽인지 먼저 묻습니다.

## 멈춰야 하는 신호

아래 중 하나에 해당하면 고치지 않고 멈춘 뒤 개발자와 이야기합니다.

1. 지금 화면이 받고 있지 않은 데이터가 필요합니다.
2. 값을 계산하는 방식이 바뀝니다.
3. 무엇이 언제 저장되거나 전송되는지가 바뀝니다.
4. 누가 볼 수 있고 누가 할 수 있는지의 조건이 바뀝니다.

멈춘다고 해서 작업 전체가 멈추는 것은 아닙니다. 필요한 데이터를 목록으로 정리해 개발자에게 요청하고, 뷰는 임시 데이터로 먼저 만들어 둘 수 있습니다. 임시 데이터를 한 파일에 모아 두면 개발자가 나중에 그 파일만 실제 데이터 연결로 바꾸면 됩니다.

## 실제 코드는 깔끔하게 나뉘어 있지 않을 수 있습니다

한 파일 안에 뷰와 데이터 요청과 로직이 섞여 있는 경우가 흔합니다. 이럴 때는 파일 단위가 아니라 파일 안의 부분 단위로 구분해야 합니다. 어느 폴더와 파일이 뷰인지는 레포마다 다르고, 레포 단위(C2)에서 다룹니다.

## AI에게 이렇게 말합니다

- "이 파일에서 뷰에 해당하는 부분과 데이터 요청, 로직에 해당하는 부분을 나눠서 알려줘. 코드는 수정하지 마."
- "내가 하려는 변경이 뷰만 고치면 되는지, 데이터 요청이나 로직도 바꿔야 하는지 먼저 알려줘."
- "이 변경에서 데이터를 가져오는 코드나 로직을 고쳐야 하게 되면, 고치지 말고 멈춰서 무엇이 왜 필요한지 설명해줘."
- "필요한 데이터가 아직 없으니 임시 데이터로 뷰를 먼저 만들어줘. 임시 데이터는 파일 하나에 모으고, 임시라는 것을 주석으로 표시해줘."
