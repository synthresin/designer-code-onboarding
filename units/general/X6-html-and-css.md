# HTML과 CSS로 형태가 기술되는 방식

웹 화면은 두 가지 언어로 기술됩니다. HTML은 화면에 어떤 요소가 어떤 구조로 있는지를 적고, CSS는 그 요소들이 어떤 모양인지를 적습니다. 컴포넌트로 쓴 화면 코드도 브라우저에 도달할 때는 HTML과 CSS가 됩니다. 단위 B6에서 다룬 부모와 자식의 구조가 실제로 어떤 문법으로 적히는지 알고 싶은 사람을 위한 글입니다.

## HTML: 구조

HTML은 요소를 태그로 적습니다. 여는 태그와 닫는 태그 사이에 들어 있는 것이 그 요소의 자식입니다.

```
<section>
  <h2>휴가 신청</h2>
  <p>남은 휴가 12일</p>
  <button>신청하기</button>
</section>
```

태그의 이름에는 뜻이 있습니다. `h2`는 제목, `p`는 문단, `button`은 버튼입니다. 뜻이 따로 없는 묶음에는 `div`를 씁니다. 뜻에 맞는 태그를 쓰면 화면을 읽어 주는 보조 도구와 키보드 조작이 제대로 동작합니다. 모양은 같아도 `div`로 만든 버튼과 `button`으로 만든 버튼은 접근성에서 다릅니다.

## CSS: 모양

CSS는 "어떤 요소에, 어떤 속성을, 어떤 값으로"를 적습니다.

```
.card {
  padding: 16px;
  border-radius: 8px;
  background-color: white;
}
```

`.card`는 대상을 고르는 부분이고, 중괄호 안의 각 줄이 속성과 값입니다.

## 모든 요소는 상자입니다

브라우저는 모든 요소를 사각형 상자로 다룹니다. 상자는 안쪽부터 네 겹입니다.

| 겹 | 뜻 | Figma에서 |
| --- | --- | --- |
| 내용(content) | 글자나 자식 요소가 들어가는 영역 | 프레임의 내용 |
| 안쪽 여백(padding) | 내용과 테두리 사이 | 오토레이아웃의 패딩 |
| 테두리(border) | 상자의 선 | 스트로크 |
| 바깥 여백(margin) | 이 상자와 옆 상자 사이 | 대응하는 것이 없습니다. Figma에서는 부모의 간격으로 정합니다 |

## 오토레이아웃은 flexbox에 대응합니다

CSS에서 자식을 한 방향으로 나열하는 방식을 flexbox라고 합니다. Figma의 오토레이아웃과 거의 같은 개념입니다.

| Figma 오토레이아웃 | CSS |
| --- | --- |
| 오토레이아웃을 건다 | `display: flex` |
| 방향: 가로, 세로 | `flex-direction: row`, `column` |
| 항목 사이 간격 | `gap` |
| 패딩 | `padding` |
| 주축 방향 정렬 | `justify-content` |
| 교차축 방향 정렬 | `align-items` |
| 줄바꿈 | `flex-wrap: wrap` |
| 채우기(Fill) | `flex: 1`, 또는 교차축에서는 늘어나는 정렬 |
| 내용에 맞춤(Hug) | 따로 정하지 않은 기본 상태 |
| 고정(Fixed) | `width`, `height`에 값을 지정 |

세로 묶음 안에 간격 8로 나열하는 것은 이렇게 적힙니다.

```
.stack {
  display: flex;
  flex-direction: column;
  gap: 8px;
}
```

행과 열을 동시에 다루는 격자 배치에는 grid라는 다른 방식을 씁니다.

## 토큰은 값에 붙인 이름입니다

위 예시에는 `16px`, `white` 같은 값이 직접 적혀 있습니다. 실제 프로젝트에서는 값을 직접 적지 않고 디자인 토큰의 이름을 씁니다. CSS에서는 변수라는 기능으로 이것을 할 수 있습니다.

```
.card {
  padding: var(--space-4);
  background-color: var(--color-surface);
}
```

토큰의 값이 바뀌면 그 토큰을 쓰는 모든 곳이 함께 바뀝니다. Figma의 변수와 같은 역할입니다. 프로젝트가 토큰을 어떤 방식으로 쓰는지는 플랫폼 단위(B7)에서 다룹니다.

## 스타일을 적는 방식은 프로젝트마다 다릅니다

CSS를 별도의 파일에 적는 프로젝트도 있고, 화면 코드 안에 함께 적는 프로젝트도 있고, 미리 만들어 둔 짧은 이름들을 조합하는 프로젝트도 있습니다. 적는 방식은 달라도 결국 위의 속성들로 바뀝니다.

## 브라우저에서 직접 볼 수 있습니다

브라우저의 개발자 도구를 열면 지금 보고 있는 화면의 HTML 구조와, 요소마다 적용된 CSS를 볼 수 있습니다. 화면의 요소를 눌러서 그 요소의 상자 크기와 여백을 확인할 수 있고, 값을 임시로 바꿔 볼 수도 있습니다. 임시로 바꾼 값은 새로 고치면 없어집니다. 시안과 구현의 차이를 확인할 때 유용합니다.

## AI에게 이렇게 말합니다

- "이 영역의 배치가 flexbox로 되어 있는지 grid로 되어 있는지, 방향과 간격이 어떤 값인지 알려줘."
- "이 프로젝트에서 스타일을 적는 방식을 예시 하나와 함께 설명해줘."
