# AI 코딩 앱에서 프로젝트 폴더를 열고 작업을 지시하기

AI 코딩 앱(Claude Code 앱, Codex 앱)은 여러분이 열어 준 프로젝트 폴더 안에서 일합니다. 그 폴더의 파일을 읽고, 고치고, 그 폴더에서 명령을 실행합니다. 여러분은 터미널에 명령을 직접 입력하지 않습니다.

앱 화면의 구체적인 버튼 위치와 사내 설정은 레포별 셋업 단위(A6)에서 다룹니다. 여기서는 두 앱에 공통인 작업 방식을 다룹니다.

## 절차

1. 앱에서 작업할 프로젝트 폴더를 엽니다. AI는 이 폴더를 기준으로 일하므로, 다른 프로젝트를 작업하려면 그 프로젝트의 폴더를 따로 엽니다.
2. 무엇을 원하는지 문장으로 말합니다. 화면 이름, 문구, 위치처럼 여러분이 아는 단서를 그대로 적으면 AI가 해당 코드를 찾습니다.
3. AI가 파일을 고치거나 명령을 실행하기 전에 허락을 물으면, 무엇을 하려는지 읽고 결정합니다. 허락을 묻는 범위는 앱의 설정에 따라 다릅니다.
4. 작업이 끝나면 무엇을 바꿨는지 설명을 요청하고, 화면에서 결과를 확인합니다.

## 읽기만 하는 지시와 수정하는 지시

지시는 두 종류로 나눠서 말합니다.

- 읽기만 하는 지시: 설명해 달라, 찾아 달라, 알려 달라는 요청입니다. 끝에 "코드는 수정하지 마"를 붙이면 AI가 파일을 바꾸지 않습니다. 읽기 작업 범위에서는 이 종류의 지시만 씁니다.
- 수정하는 지시: 바꿔 달라, 추가해 달라, 만들어 달라는 요청입니다. 뷰 수정 작업 범위부터 씁니다.

잘 모르는 상태에서는 먼저 읽기만 하는 지시로 상황을 파악한 뒤에 수정을 요청합니다. "이걸 고치려면 어떤 파일을 어떻게 바꾸게 되는지 먼저 계획만 말해줘"라고 하면, 실제로 바꾸기 전에 AI의 계획을 볼 수 있습니다.

## AI가 명령을 실행할 때

화면을 띄우거나 변경을 저장소에 올리는 일은 터미널 명령으로 이루어집니다. 이 명령은 AI가 실행합니다. 여러분이 할 일은 두 가지입니다.

- 실행하려는 명령이 무엇을 하는지 한 문장으로 설명을 듣습니다. 설명이 없으면 물어봅니다.
- 설명이 이해되지 않거나 지금 하려는 작업과 관계가 없어 보이면 허락하지 않고 이유를 묻습니다.

## 대화가 길어지면

AI는 한 대화 안에서 나눈 내용을 기억하지만, 새 대화를 시작하면 이전 대화의 내용은 기본적으로 이어지지 않습니다. 서로 관계없는 작업은 대화를 나눠서 하는 것을 권합니다. 대화 하나에 여러 작업이 섞이면 AI가 앞의 작업 내용을 지금 작업에 잘못 적용하는 일이 생깁니다. 프로젝트마다 AI가 항상 먼저 읽는 지침 파일(AGENTS.md 등)이 있어서, 프로젝트의 규칙은 새 대화에서도 유지됩니다.

## AI에게 이렇게 말합니다

- "지금 열려 있는 폴더가 어떤 프로젝트인지 설명해줘. 코드는 수정하지 마."
- "이 작업을 하려면 무엇을 어떤 순서로 하게 되는지 계획만 먼저 말해줘."
- "방금 실행하려는 명령이 무엇을 하는 명령인지 한 문장으로 설명해줘."
- "방금 한 작업을 파일별로 무엇을 왜 바꿨는지 설명해줘."
